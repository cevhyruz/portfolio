🚀 Personal developer portfolio showcasing my projects, skills, and experiments in web development, system design, and modern JavaScript frameworks.


## Development

Starting a local development server:

```bash
npm start
```

## Building

Building the project:

```bash
npm build
```

## Testing

Execute unit tests with the [Vitest](https://vitest.dev/) test runner:

```bash
npm test
```

For e2e testing:

```bash
ng e2e
```
